HDrezka

Выберите зеркало из списка или введите собственный адрес HTTPS.
Откройте карточку видео, затем в течение двух минут запустите проверку. Она передаст временную ссылку всем серверам из списка и измерит получение небольшого фрагмента. Результат зависит от видео и нагрузки.
Необязательно: API Read Access Token для постеров и названий TMDB. Без ключа каталог создаётся с названиями транслитом. Оставьте поле пустым, чтобы сохранить текущий ключ.
Не выше обычного 1080p. Если выбранное качество недоступно, будет выбрано ближайшее доступное ниже.
Как часто обновлять каталог: от 1 до 7 дней.
