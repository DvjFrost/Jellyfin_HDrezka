# HDrezka для Jellyfin

Плагин для Jellyfin 12.4: каталог фильмов и сериалов HDrezka в обычных медиатеках Jellyfin, поиск по локальному каталогу и воспроизведение с бесплатными озвучками.

Разработчики: **Frost & Codex**. Проект находится на стадии тестирования.

## Возможности

- Создание медиатек «Фильмы HDrezka» и «Сериалы HDrezka» из файлов sitemap выбранного зеркала.
- Локальный поиск по каталогу. Ключ TMDB необязателен: с ним плагин дополняет совпавшие карточки названиями, постерами, описаниями, актёрами и другими доступными данными; без него каталог доступен с названиями транслитом.
- Получение подробностей, доступных озвучек, сезонов и серий при открытии карточки. Платные озвучки скрываются.
- Выбор озвучки в стандартном списке версий Jellyfin. Максимальное качество и ограничение качества настраиваются в плагине; обычное 1080p поддерживается, 1080p Ultra исключено.
- Выбор CDN, проверка доступных CDN, хранение сессии зеркала и автоматическая попытка обновления при проверке Anubis.
- Сохранение выбранной озвучки при автоматическом переходе к следующей серии при доступности этой озвучки.
- Загрузка фильмов и серий в локальные медиатеки с выбором бесплатной озвучки и качества; управление очередью находится на отдельной странице панели управления.
- Названия серий из расписания сайта, когда они доступны.

Функции зависят от доступности зеркала, сайта и CDN. Cloudflare не поддерживается.

## Установка через репозиторий Jellyfin

Проверено на **Jellyfin Server 12.4**. Совместимость с другими версиями отдельно не проверялась.

1. Откройте **Панель управления → Плагины → Репозитории**.
2. Добавьте репозиторий с названием `HDrezka` и адресом:

   ```text
   https://raw.githubusercontent.com/DvjFrost/Jellyfin_HDrezka/main/manifest.json
   ```

3. В каталоге плагинов найдите **HDrezka** и установите его, затем перезапустите сервер.
4. Откройте настройки плагина, укажите доступное зеркало HTTPS и при необходимости введите **TMDB API Read Access Token**.
5. После создания каталога Jellyfin просканирует медиатеки. Первое сопоставление с TMDB может занять продолжительное время; результаты сохраняются.

После публикации новой версии её можно будет установить из каталога плагинов Jellyfin. Если плагин ранее устанавливался вручную и появился дважды, остановите Jellyfin, сохраните резервную копию старой папки плагина и уберите дублирующую папку. Папки медиатек, данные и настройки сервера не удаляйте.

## Ручная установка

Скачайте [HDrezka-v0.3.1.zip](https://raw.githubusercontent.com/DvjFrost/Jellyfin_HDrezka/main/packages/HDrezka-v0.3.1.zip). Остановите Jellyfin, распакуйте содержимое архива в отдельную папку `plugins/HDrezka`, затем запустите сервер. Все файлы архива должны лежать непосредственно в этой папке.

## Настройки и работа

В настройках доступны зеркало, CDN, ключ TMDB, ограничение качества и интервал обновления каталога. Плагин запускает индексирование при старте сервера и далее через указанный интервал. При наличии ключа задание TMDB работает отдельно после индексирования. Сопоставления и данные медиатек хранятся на сервере Jellyfin.

Статистика показывает совпадения, неоднозначные результаты и позиции без совпадений TMDB. Если совпадение не найдено, данные с зеркала могут загрузиться при открытии карточки. Названия, которые были изменены вручную или заблокированы, автоматическое исправление транслита не заменяет.

В карточке можно выбрать «Определить» и применить результат встроенного поиска Jellyfin. Настройки библиотек HDrezka включают сохранение метаданных в NFO и TMDB для фильмов и сериалов; для вариантов отдельных серий дополнительный поиск не включается. Изменения библиотек применяются при очередном запуске задания синхронизации HDrezka.

Ссылки на видео получаются при воспроизведении и могут меняться. Для доступа к зеркалу используется сохраняемая серверная сессия. Реальное повторное появление Anubis при истечении сессии проверено не во всех условиях.

## Сборка и тесты

Нужны .NET SDK 10 и доступ к пакетам NuGet:

```sh
dotnet test tests/Jellyfin.Plugin.Hdrezka.Tests/Jellyfin.Plugin.Hdrezka.Tests.csproj
dotnet build src/Jellyfin.Plugin.Hdrezka/Jellyfin.Plugin.Hdrezka.csproj -c Release
```

Архив релиза содержит `Jellyfin.Plugin.Hdrezka.dll`, `HtmlAgilityPack.dll`, `icon.png` и `meta.json`. При подготовке новой версии нужно обновить номер сборки и манифест, собрать архив, указать в `manifest.json` ссылку на него и MD5 именно готового архива, а затем опубликовать релиз.
